## Independent adversarial matrix and holds

1. **Credential provenance:** `SERVICEDESK_CODEX_GATEWAY_KEY` must be provisioned only through a verified V4 secret store. Do not export or repurpose personal Codex OAuth tokens or put a key in frontend code, repository commits, GitHub CI logs, provider error responses or untrusted query parameters. No active deployment has been configured in this batch.
2. **Single-workspace authorization:** a gateway-enabled deployment must specify one exact `SERVICEDESK_CODEX_GATEWAY_TEST_WORKSPACE_ID` UUID. Runtime refuses missing/invalid IDs, and transport refuses any input.workspaceId different from this value before network access. No production multi-tenant usage under one personal session.
3. **Double opt-in:** `SERVICEDESK_AI_ENABLED=true` **and** `SERVICEDESK_CODEX_GATEWAY_ENABLED=true` must be set, in addition to explicit `SERVICEDESK_AI_PROVIDER=codex_gateway`; the normal official OpenAI model remains the default. Fail on missing key, unsupported alias, invalid origin, URL credentials/ports, downgrade and unauthorized provider selection before dispatch.
4. **Outbound restriction:** only `https://codex-api.ezcomo.shop/v1/chat/completions` may receive the gateway bearer token. Preserve `redirect:error`, `no-store`, timeouts, cancellation and bounded HTTP streaming. The existing official `https://api.openai.com/v1/responses` route must continue working.
5. **Response integrity:** one `chat.completion` with exactly one index-zero completed assistant message, bounded JSON string and no `tool_calls`, `function_call` or `refusal`. Apply original ServiceDesk structured output guard. Non-JSON, partial and tool-bearing responses cannot trigger application business commands.
6. **Existing auth:** only authenticated staff may request saved-record AI; owner-only model connection test and owner brief. No gateway can bypass tenant-scoped source reads, human approval before customer messages, real quote prices, job dispatch or payments.
7. **Provider uncertainty:** the custom gateway ignores `max_output_tokens`, so the model may spend unbounded reasoning until the CLI timeout, although ServiceDesk caps input length and HTTP response bytes. A 30-second timeout can be too short for CLI startup; appropriate quotas, usage governance and model-alias support need independent real tests.
8. **Commercial authorization:** a shared operator-owned ChatGPT/Codex session is **not automatically** a permitted multi-tenant SaaS API; consult participating Sign in with ChatGPT commercial app requirements and account terms. **No merchant-facing production traffic** until explicitly supported authorization, per-tenant consent, privacy, financial and capacity review.
