# SONIC L20 — opt-in safe aftercare follow-up review

This source policy turns a trusted, committed completed-visit event, exact saved visit version and recipient contact permission into an owner-review candidate. It refuses wrong tenant/visit/version/clock, missing opt-in, opt-outs, quiet hours, expired receipts and incomplete visits. Never creates an external message, decides customer contact channel, fabricates provider delivery or charges customers. It cannot run automatically until real server journal/recipient facts are wired by connector team; this contract is a safe prerequisite for event-driven aftercare.

Tests use fictional records only. Does NOT demonstrate successful real customer outreach.
