# R43 L26 — Proposed-vs-saved published rule overlap review

Complements L24 draft-vs-draft conflict preflight by checking proposed internal attention rules against a supplied tenant/branch-scoped inventory of PUBLISHED rule versions. Distinguishes definite same-event or exact service-code overlap, provably distinct catalog service filters and possible unconditional shadows. Refuses missing/foreign/duplicate/hidden malformed rows. Even a clean supplied inventory returns `completeInventoryNotProven:true`: a caller must verify pagination completeness and owner role/branch before showing a result. This pure function does not load the database, publish or execute rules, invoke an AI model, send provider messages or change financial state. Integration into the signed-in owner's rule inventory is separately required.
