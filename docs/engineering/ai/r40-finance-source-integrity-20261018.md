# SONIC R40 finance saved source authority

The owner finance agent's ledger exception planner accepts only explicitly saved DTO fields in a plain own-property invoice. A synthetic/connector-injected object with hidden payment/provider data, an accessor, a forged prototype or unknown keys cannot be silently treated as authoritative ledger evidence. A bounded invoice collection at exactly the source limit also cannot certify complete financial review. This produces human review candidates only and never acknowledges charge, refund or customer notification. The signed-in double-read wrapper and its 300-row loader cap remain unchanged.

Tests cover valid saved invoices, hidden fields, non-enumerable/symbol/accessor attacks, metadata-bearing or sparse arrays, unknown financial authorization fields and a full source limit. No deployment or financial mutation.
