# R43 L24 — Automation portfolio preview / duplicate-risk review

This adds a trusted owner-only **portfolio conflict preview** over compiler-produced, unpublished internal-action drafts. It detects duplicate unconditional triggers, unconditional rules that would also fire alongside service-specific rules, and repeated service-specific event conditions across a bounded 25-draft batch. All drafts must match exact owner/workspace/branch, one internal CREATE_ATTENTION action, and the existing approved event catalogue. It is neither a query of published database rules nor proof that owners should publish; no model/provider call, business mutation, automated sends or approval. Product Studio may offer it as a prepublication warning only after signed-in owner resolver and saved-source checks.
