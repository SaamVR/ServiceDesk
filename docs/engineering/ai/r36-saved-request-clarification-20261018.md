# SONIC R36 AI-D — deterministic saved request clarification

The authorized request copilot can produce genuine, source-backed missing-information checks from the exact saved service code, bedroom/bathroom counts and status. The assistant passes the allowlisted *missing field names* into the model prompt, then returns fixed text checks alongside the AI advisory after existing post-model actor/source revalidation. This reduces hallucinated clarification questions and gives a reliable machine-readable staff follow-up action list.

This function does not contact any customer or update a request. The current UI client parser discards additional response fields; owner UX integration is separately owned by frontend. No merchant acceptance or provider success is claimed.
