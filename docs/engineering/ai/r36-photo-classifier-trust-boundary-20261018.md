# SONIC R36 multimodal photo classification proposal boundary

Improves an existing AI-powered photo-intake feature, not a decorative new component. Only a consented, explicitly non-training image byte buffer can enter classification, with bounded category/add-on allowlists. Model category proposals must use an exact data-object shape; pricing, booking, provider truth, hidden fields and unknown effects are rejected before any data is read. Follow-up questions are bounded dense arrays without getters/PII injections.

This is safe classification proposal validation, not proof a provider processed a real photo, nor a quote or completed job. No model training, image upload, messages, financial state or provider delivery performed here.
