# R34 internal AI owner workflow suggestion HTTP entrypoint
Adds protected `POST /api/internal/ai/workflow-suggestion` for the owner-only model-to-rule draft service. Only exact bounded JSON fields, same-origin or strictly configured trusted public origin, no-store status, no provider token/log/PII echo. The server runner performs owner and saved-branch double check and returns only nonpublished, one-internal-attention suggestion; no autonomous publication/delivery. Frontend workbench wiring and signed-in browser test are separate lane. Source mock HTTP contract is not live service acceptance.
