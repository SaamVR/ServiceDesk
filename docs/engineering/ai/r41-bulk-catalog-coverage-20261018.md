# R41 AI-C — Bulk synthetic automation coverage

Uses the existing real workflow preview evaluator and all 27 catalog starter rules to inspect up to 12 fictional owner-provided event scenarios in one deterministic call. Emits scenario-by-scenario template matches and unique starter coverage, not just a preset count. The entire batch fails closed on any tenant mismatch, forged persisted event identity, hidden source, missing/duplicate ID or unsupported event fields. Cannot publish a rule, create an attention, charge or contact a customer.

This is a callable backend acceptance/UX building block, not a scheduler or live event listener. UI may surface it once owned and deployed, with explicit "synthetic" labels and separate owner authorization. Real merchant UAT and migrations remain unverified in this source-only feature.
