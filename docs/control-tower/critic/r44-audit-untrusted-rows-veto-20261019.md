# R44 Independent Critic — untrusted AI audit rows
The generic action-audit serializer treats model/provider tool results as untrusted, but still uses `tools.filter(item=>item.outcome)` and downstream property reads before checking own data descriptors. Getter traps can throw and hidden action keys evade reviewer visibility. This critic branch injects both an accessor and hidden secret into tool result rows, requiring fail-closed sanitized BLOCKED rows. Any completed claim still needs independent persisted evidence verification. Test only; the producer must fix before integration.
