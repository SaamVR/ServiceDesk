# R37 independent critic — AI model side-channel safety

A blocked model tool name can contain arbitrary untrusted string content. Even
though the provider action is suppressed, its name was echoed into the
human-review decision and therefore potentially a staff UI/log. Also a forged
model envelope could expose an accessor that throws when the planner reads it.
The candidate must mask unknown tool names and reject getter/accessor model
envelopes before dereferencing. The critic's separate tests run without
secrets, customer records or provider/network calls.
