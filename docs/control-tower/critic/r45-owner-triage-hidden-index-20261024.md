# R45 Independent critic — non-enumerable recovery rows

A saved failure batch must correspond exactly to the enumerable records the operator and serializer saw. A hidden/nonenumerable own index could have passed an existing descriptor-value check while being excluded from JSON logs and counted from indexed iteration, making operational audit ambiguous. Require each dense array index enumerable as well as a plain data property. This is a test-only critic change on a separate branch; producer owns code correction before merge. No real customer data.
